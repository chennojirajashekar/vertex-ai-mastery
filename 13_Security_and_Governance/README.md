# 11. Security & Governance

## Overview
Enterprise AI requires robust security and governance to protect data and ensure compliance.

## Key Security Features
- **VPC Service Controls (VPC-SC):** Creating a security perimeter around your resources.
- **Private Endpoints:** Ensuring your model endpoints are only accessible within your private network.
- **Data Encryption:** Using Customer-Managed Encryption Keys (CMEK) for data at rest.
- **IAM Roles:** Implementing the principle of least privilege for service accounts.

## Governance & Responsible AI
- **Model Monitoring:** Detecting drift and bias in production.
- **Safety Filters:** Configuring thresholds for Gemini and other models.
- **Explainability:** Understanding why models make certain predictions.
