# 04. AutoML (Elite Level)

## What is AutoML?
AutoML uses Google's state-of-the-art neural architecture search to automatically find the best model for your data.

## Supported Data Types
- **Tables:** Predict numerical or categorical values from structured data.
- **Vision:** Image classification, object detection, and segmentation.
- **Video:** Action recognition and object tracking.
- **NLP:** Sentiment analysis, entity extraction, and text classification.

## AutoML vs. Custom vs. Foundation Models
- **AutoML:** High performance, low effort, less control.
- **Custom:** Full control, higher effort.
- **Foundation Models (Gemini):** Great for GenAI and complex reasoning without training.

## Cost Traps
AutoML can be expensive if you train on very large datasets without monitoring. Use budget alerts!
