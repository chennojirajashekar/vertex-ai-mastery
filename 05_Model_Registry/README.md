# 05. Model Registry

## Overview
Model Registry is your "library" of models. It allows you to organize, version, and manage the lifecycle of your ML models.

## Key Features
- **Versioning:** Track different versions of the same model (e.g., `v1`, `v2`).
- **Lineage:** See which dataset and training job produced a specific model version.
- **Aliases:** Assign aliases like `production` or `staging` to specific versions.

## Lifecycle Management
- **Approval Workflows:** Ensure a model is reviewed before being deployed to production.
- **CI/CD Integration:** Automatically register new models after successful training.
