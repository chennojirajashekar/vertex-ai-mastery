# Real-World Projects

This section contains end-to-end projects demonstrating the power of Vertex AI in production scenarios.

## Projects Overview

### 1. End-to-End Tabular Pipeline
- **Use Case:** Fraud detection for financial transactions.
- **Tech Stack:** Vertex AI Pipelines, AutoML Tables, BigQuery ML.
- **Goal:** Automate data ingestion, training, and deployment with model monitoring.

### 2. Computer Vision: Defect Detection
- **Use Case:** Identifying defects in manufacturing lines.
- **Tech Stack:** Vertex AI Custom Training (PyTorch), Artifact Registry, Online Endpoints.
- **Goal:** Build a custom CNN and serve it with low latency.

### 3. GenAI: Enterprise Multi-Document RAG
- **Use Case:** Querying internal company documentation.
- **Tech Stack:** Gemini 1.5 Pro, Vertex AI Vector Search, LangChain.
- **Goal:** Implementing a robust retrieval-augmented generation system.

### 4. Custom Transformers at Scale
- **Use Case:** Sentiment analysis for global social media streams.
- **Tech Stack:** Custom Training (Hugging Face), Distributed Training on GPUs.
- **Goal:** Training and serving large-scale NLP models.

### 5. Architectural Blueprints
- **Objective:** Best practices for multi-project setups (Dev/Staging/Prod).
- **Focus:** Security, isolation, and CI/CD integration.
