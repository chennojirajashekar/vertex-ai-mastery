# 00. Fundamentals (Foundational)

## What is Vertex AI?
Vertex AI is Google Cloud's unified machine learning platform. It brings together all the services you need to build, deploy, and scale AI models in one place.

### Why Vertex AI?
- **Unified Experience:** No more switching between different tools.
- **Enterprise Grade:** Built on Google's infrastructure with high security and reliability.
- **Scalability:** Easily handle everything from small datasets to massive models.

### Vertex AI vs. Others
- **Vertex AI (GCP):** Best integration with BigQuery and Dataflow.
- **SageMaker (AWS):** Powerful but can be complex.
- **Azure ML (Microsoft):** Great for those already in the Microsoft ecosystem.

## Core Architecture
Vertex AI is divided into several core components:
1. **Workbench:** Jupyter notebooks for experimentation.
2. **Pipelines:** Orchestrate your ML workflows.
3. **Model Registry:** Manage your model versions.
4. **Endpoints:** Serve your models for predictions.

## Global vs. Regional Services
- **Global:** Accessible from anywhere but might have higher latency.
- **Regional:** Data stays within a specific region (important for compliance).
