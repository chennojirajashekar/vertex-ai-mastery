# 07. MLOps with Vertex

## Overview
MLOps (Machine Learning Operations) with Vertex AI involves automating and monitoring the entire ML lifecycle using Vertex Pipelines and other tools.

## Key Components
- **Vertex Pipelines:** Orchestrate ML workflows using Kubeflow or TFX.
- **Model Monitoring:** Detect skew and drift in production models.
- **Vertex ML Metadata:** Track artifacts and lineage across the lifecycle.
- **CI/CD Integration:** Automated testing and deployment with GitHub Actions.

## Best Practices
- **Reproducibility:** Versioning data, code, and models.
- **Automation:** Reducing manual intervention in the pipeline.
