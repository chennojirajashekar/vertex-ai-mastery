# 09. Vector Search & RAG

## Overview
Vector Search (formerly Matching Engine) and Retrieval-Augmented Generation (RAG) enable advanced search and LLM grounding.

## Key Features
- **Vertex AI Vector Search:** High-scale, low-latency similarity search.
- **Embeddings:** Generate vector representations for text and images.
- **Grounding with Google Search:** Enhance Gemini with live web data.
- **Grounding with Vertex AI Search:** Connect Gemini to your structured/unstructured data.

## RAG Architecture
- **Document Ingestion:** Preparing data for embedding and indexing.
- **Retrieval:** Fetching relevant context for the LLM.
- **Generation:** Gemini generating answers based on retrieved context.
