# 06. Model Deployment

## Overview
Model Deployment in Vertex AI allows you to serve your models for predictions. This chapter covers online endpoints, batch predictions, and deployment strategies.

## Key Features
- **Online Endpoints:** Scalable, low-latency prediction service.
- **Batch Prediction:** For processing large datasets asynchronously.
- **Traffic Splitting:** Canary deployments and A/B testing.
- **Autoscaling:** Automatically adjust resources based on demand.

## Deployment Strategies
- **Multi-region deployment:** Ensuring high availability.
- **Latency Optimization:** Reducing response times for real-time apps.
